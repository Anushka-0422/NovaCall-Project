# 🚀 NovaCall – Real-Time Video Conferencing & Live Chat Platform

NovaCall is a full-stack real-time communication platform designed to enable seamless video conferencing and live messaging. The system is being built with a scalable architecture, separating frontend and backend services for flexibility and performance.

---

## 🌟 Key Features

* 💬 **Live Chat System** (Implemented)
  Real-time messaging with a responsive UI for smooth user interaction.

* 🎥 **Video Conferencing** (In Progress)
  Integrating peer-to-peer communication using WebRTC for low-latency video streaming.

* ⚡ **High-Performance Frontend**
  Built with Vite + React for fast development and optimized builds.

* 🔗 **REST API Backend**
  Modular backend using Node.js and Express.js for handling user sessions and communication.

* 📡 **Real-Time Communication (Planned/Partial)**
  Socket.io integration for live updates and signaling.

* 📱 **Responsive Design**
  Optimized for both desktop and mobile devices.

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/novacall.git
```

### 2. Setup Backend

```
cd backend
npm install
npm start
```

### 3. Setup Frontend

```
cd frontend
npm install
npm run dev
```
